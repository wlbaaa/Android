关于 Android 12 Web Emulator

这是什么？

这是一个基于 Web 技术构建的 Android 12 (Material You) 风格的模拟器界面。它通过嵌入 appetize.io 的云端 Android 模拟器，实现了在浏览器中运行真实 APK 的能力。

技术架构

前端使用纯 HTML/CSS/JavaScript 实现 Android 12 Material You 设计系统，包括：

- Material You 动态色彩系统（支持亮/暗主题）

- Android 12 桌面、状态栏、手势导航

- 通知面板与快捷设置

- 通过 iframe 嵌入 appetize.io 云端模拟器

如何使用

1. 点击"上传 APK"选择 .apk 文件

2. APK 会被上传到 appetize.io 云端

3. 上传完成后，在"APK 运行器"中查看运行效果

4. 你可以像使用真实 Android 设备一样操作

注意事项

- 需要 appetize.io API Token 才能上传 APK（免费额度有限）

- APK 运行在云端服务器上，需要网络连接

- 免费套餐有并发会话限制
